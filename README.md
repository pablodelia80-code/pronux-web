# ProNux

Web de ProNux: webs a medida para comercios y pymes.

Sitio estático (HTML, CSS y JavaScript), sin dependencias ni compilación. Se publica tal cual desde la raíz del repo.

- `index.html`, `servicios.html`, `trabajos.html`, `nosotros.html`, `planes.html`, `contacto.html`: páginas
- `css/estilos.css`, `js/main.js`: estilos y animaciones compartidas
- `img/`: capturas e íconos usados en la web
- `marca/`: logo de ProNux en SVG y PNG
